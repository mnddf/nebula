# NEBULA · 让画面动起来

一个基于 Three.js 的单屏 3D 动画网页，深色极简风格，全屏粒子星云作为背景，支持鼠标/触控视差交互。

## 1. 项目解决什么问题

传统网页以静态图文为主，视觉表现力有限。本项目展示如何用少量代码在浏览器中实现实时 3D 动画效果，适合作为个人主页、产品落地页或创意展示的起步模板。

## 2. 主要功能

- **全屏 Canvas 3D 背景**：使用 Three.js 渲染，深色底 `#0A0A0B`
- **粒子星云效果**：2500 个圆形粒子按螺旋分布，冷色调（蓝 / 青 / 紫），缓慢旋转并上下波动
- **中心几何线框**：内外双层二十面体线框几何体反向旋转
- **鼠标 / 触控视差**：指针或手指滑动时，相机与粒子产生轻微 3D 纵深感偏移
- **进入体验按钮**：点击后粒子加速旋转 2 秒
- **文字淡入动画**：标题、副标题、按钮依次淡入上浮
- **响应式布局**：适配桌面、平板、手机，支持横竖屏切换
- **WebGL 容错**：环境不支持 WebGL 时显示提示，UI 仍可正常渲染

## 3. 安装方法

本项目是纯静态网页，无需安装依赖。

### 方式一：直接打开

下载 `index.html`，双击用浏览器打开即可。

### 方式二：本地服务器（推荐，避免浏览器本地文件限制）

```bash
# 进入项目目录
cd nebula

# 启动本地服务器（任选其一）
python3 -m http.server 8080
# 或
npx serve

# 浏览器访问 http://localhost:8080
```

### 方式三：部署到 GitHub Pages

1. 将 `index.html` 上传到名为 `你的用户名.github.io` 的仓库
2. 在仓库 Settings → Pages 中选择 main 分支
3. 访问 `https://你的用户名.github.io`

## 4. 使用方法

| 操作 | 效果 |
|------|------|
| 打开网页 | 自动播放粒子星云动画，文字依次淡入 |
| 移动鼠标 / 手指滑动 | 相机与粒子产生视差偏移，呈现 3D 纵深 |
| 点击「进入体验 →」 | 粒子加速旋转 2 秒 |
| 旋转屏幕 / 调整窗口 | 画布自动适配新尺寸 |

## 5. 输入输出示例

### 输入

无额外输入参数。所有效果由代码内置配置驱动，关键可调参数如下：

```javascript
// 粒子数量
const particleCount = 2500;

// 相机距离
camera.position.set(0, 0, 9);

// 粒子旋转速度
particles.rotation.y = t * 0.04 + targetX * 0.2;

// 中心几何体尺寸
const coreGeo = new THREE.IcosahedronGeometry(1.6, 0);
```

### 输出

浏览器中渲染出一个深色背景的 3D 粒子星云动画页面，包含：
- 顶部半透明导航栏（NEBULA / 作品 / 关于 / 联系）
- 中央大标题「让画面动起来」+ 副标题 + 按钮
- 底部版权与技术标识
- 全屏旋转波动的冷色调粒子星云与线框几何体

## 技术栈

- HTML5 + CSS3
- Three.js 0.160.0（通过 CDN 引入）
- WebGL 渲染
